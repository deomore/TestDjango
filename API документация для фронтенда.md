# **🎮 Game Project API Guide**

Привет\! Это краткая справка по работе с бэкендом.  
Здесь описано, как получать данные, какие поля приходят и как теперь (наконец-то\!) удобно работать со связанными объектами.  
**Base URL:** http://localhost:8000/api/ (локально)

## **🔥 Главное обновление: Чтение vs Запись**

Чтобы тебе не приходилось искать ID стран или студий по их названию, мы разделили поля:

1. **\_details поля (Только для чтения)**: В них приходят полные объекты. Используй их для отрисовки интерфейса.  
2. **Обычные поля (Только для записи)**: Сюда ты отправляешь id при создании или редактировании.

## **1\. Игры (/games/)**

Самый жирный эндпоинт. Теперь тут есть категории и нормальная вложенность.  
**GET** /api/games/  
Получение списка игр.  
**Пример ответа:**  
\[  
    {  
        "id": 1,  
        "name": "Cyberpunk 2077",  
        "description": "Описание игры...",  
        "release\_year": 2020,  
        "dls\_count": 1,  
        "preview": "http://localhost:8000/media/game\_previews/img.jpg",  
        "comments\_count": 42,  
          
        // 👇 ВОТ ОНО\! Готовые объекты для вывода  
        "studio\_details": {  
            "id": 5,  
            "name": "CD Projekt RED",  
            "country\_details": { "id": 10, "name": "Poland" }  
        },  
        "publisher\_details": {  
            "id": 5,  
            "name": "CD Projekt",  
            "country\_details": { "id": 10, "name": "Poland" },  
            "founded": "2002-05-01"  
        },  
        "categories\_details": \[  
            { "id": 1, "name": "RPG" },  
            { "id": 2, "name": "Shooter" }  
        \]  
    }  
\]

**POST** /api/games/  
Создание игры. Тут мы отправляем только **ID**.  
**Тело запроса:**  
{  
    "name": "New Game",  
    "description": "Крутая игра",  
    "release\_year": 2024,  
    "studio": 5,          // ID студии  
    "publisher": 5,       // ID издателя  
    "categories": \[1, 2\], // Массив ID категорий  
    "preview": (файл картинки)  
}

## **2\. Новости (/news/)**

Новый раздел. Картинка приходит ссылкой.  
**GET** /api/news/  
**Пример ответа:**  
\[  
    {  
        "id": 1,  
        "title": "Большое обновление\!",  
        "content": "Текст новости здесь...",  
        "image": "http://localhost:8000/media/news\_images/news1.jpg",  
        "created\_at": "2023-11-23T10:00:00Z"  
    }  
\]

## **3\. Справочники (Для фильтров и селектов)**

Используй эти эндпоинты, чтобы заполнять выпадающие списки (Dropdowns) при создании игр или фильтрации.

* **Категории (Жанры):** /api/categories/  
  * Приходит: \[{"id": 1, "name": "RPG"}, ...\]  
* **Студии:** /api/studios/  
  * Приходит: \[{"id": 1, "name": "Valve", "country\_details": {...}}, ...\]  
* **Страны:** /api/countries/  
  * Приходит: \[{"id": 1, "name": "USA"}, ...\]

## **4\. Комментарии (/comments/)**

**GET** /api/comments/  
Список всех комментов.  
**POST** /api/comments/  
Добавить коммент.  
**Тело запроса:**  
{  
    "email": "user@example.com",  
    "comment": "Игра топ\!",  
    "game": 1  // ID игры  
}

## **💡 Полезные советы**

1. **Картинки:** Если поле preview или image равно null, ставь какую-нибудь заглушку на фронте.  
2. **Даты:** Даты приходят в формате ISO 8601 (например, 2023-11-23T10:00:00Z). Их нужно форматировать в JS.  
3. **Auth:** Для GET запросов авторизация не нужна. Для POST/PUT/DELETE нужен токен (если ты не админ).

*Удачи с фронтом\! Теперь никаких поисков ID по названию страны\!* 🚀
